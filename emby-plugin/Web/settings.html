仅整理直接放在库根目录的散文件，不改动已有子目录里的视频，不覆盖目标文件。电影和剧集库须开启 NFO 保存器和“将图片保存到媒体文件夹”，并对 Emby 可写。打开媒体库设置
至少两次检查确认大小和修改时间不变。检查频率在 Emby 的 计划任务 中配置（任务：Organize loose library videos，默认每 2 分钟）。
作品目录与视频命名

命名预览

可输入自己的文件名测试。不读取磁盘，也不修改视频。

模板说明

每个模板只生成一级名称，文件模板不填扩展名。年份、TMDB ID 从文件名读取，不会为命名先联网刮削。保留 {original} 就不会重命名视频。{original} 或 ${itemTitle} 是不含扩展名的原文件名，{work} 是原作品名，{title} 是从文件名提取的标题。{year_suffix} 和 {tmdb_suffix} 只在文件名里存在对应信息时生成标记。

支持 ani-rss 的 ${title} S${seasonFormat}E${episodeFormat}、${subgroup} 和 ${resolution}。缺少字幕组时会省略 [${subgroup}]。分集可用 {episode_code} 保留合集范围。
