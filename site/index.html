GET STARTED

本地部署 Web 版

需要 Docker 和 Compose v2.24.4 或以上版本。复制示例配置后，先设置一个新的 POSTGRES_PASSWORD，再启动容器。

启动后在运行 Docker 的电脑上打开 http://127.0.0.1:8080。此站点仅提供说明，不托管你的媒体库。

Docker 部署文档 · macOS / Windows 桌面版

git clone https://github.com/guangl/collect-metadata.git
cd collect-metadata
cp .env.example .env
# 在 .env 中设置 POSTGRES_PASSWORD 后再启动
docker compose -f compose.yaml -f compose.ghcr.yaml up -d
